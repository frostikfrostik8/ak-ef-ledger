# Языки / Languages

Здесь лежат переводы интерфейса AK:EF Ledger.
UI translations for AK:EF Ledger live here.

- `ru.json` — русский (базовый);
- `en.json` — английский (черновик);
- `xx.json` — любой новый язык.

## Добавить язык / Add a language

1. Скопируйте `en.json` в `xx.json` (например, `de.json`).
2. В `xx.json` поменяйте:
   - `"_languageName": "Deutsch"` — название в списке языков;
   - `"_culture": "de-DE"` — культура для чисел и дат.
3. Переведите значения. Ключи (`nav_overview`, `resource_sanity`, …) не
   меняйте.
4. В приложении: **Настройки → Язык интерфейса → кнопка перечитывания**
   (круглая стрелка) или перезапустите приложение.
5. Выберите новый язык в списке.

Если ключ не переведён, он берётся из `en.json`, затем из `ru.json`.
Недостающие ключи можно не добавлять — приложение покажет английский вариант.

## Notes

- Файлы должны быть в кодировке UTF-8 и валидным JSON.
- Служебные поля начинаются с `_`; их не нужно переводить как обычные ключи.
- `--lang=xx` — разовый запуск с языком `xx` для проверки, без сохранения.
- Явный выбор языка хранится в `%LOCALAPPDATA%\AkEfLedger\settings.json`.
- Правки `ru.json`/`en.json` могут быть перезаписаны при обновлении
  приложения. Для собственного перевода лучше делать отдельный `xx.json`.
