# Локализация / Localization

AK:EF Ledger переключает язык интерфейса **без перезапуска**, определяет язык
по системе и хранит переводы во внешних файлах `lang/*.json`.

## Как это работает

- `LocalizationService` читает `lang/ru.json`, `lang/en.json` и любые другие
  `lang/*.json` рядом с exe.
- Встроенные RU/EN — резерв: если папка `lang` удалена или файл недоступен,
  приложение продолжает работать.
- XAML использует разметку `{loc:Loc key}`, код — `L.T("key")` или
  `L.T("key", args)`.
- При смене языка сервис поднимает `PropertyChanged("Item[]")`, все биндинги
  перечитываются, а главное окно пересоздаёт текущую страницу. Открытая
  карточка оператора обновляет `DataContext` сама.
- Diff-строки и даты пересчитываются в новом языке; снапшот перечитывается из
  SQLite.

## Автоопределение

1. Если в `%LOCALAPPDATA%\AkEfLedger\settings.json` есть `"language": "ru"` /
   `"en"` — используется он.
2. Если выбрано `"language": "auto"` или файла нет — берётся
   `CultureInfo.CurrentUICulture` (язык интерфейса Windows).
3. Если для языка системы нет файла перевода — используется `en`, затем `ru`.

Настройка «Авто (системный)» при первом запуске не создаёт файл настроек: язык
определяется по системе. Если пользователь явно выбрал «Авто» после другого
языка, в файле сохраняется `"language": "auto"`. Явный выбор языка также
сохраняется в `%LOCALAPPDATA%\AkEfLedger\settings.json`.

## Формат файла

```json
{
  "_languageName": "Русский",
  "_culture": "ru-RU",
  "_dateFormat": "dd MMM yyyy, HH:mm",
  "_dateFormatShort": "dd MMM yyyy",

  "nav_overview": "Обзор",
  "resource_sanity": "РАССУДОК",
  "overview_archive_count": "в архиве: {0} снимков",
  "status_snapshot_ready_id": "Снимок #{0} готов за {1:0.0} с"
}
```

- Ключи — `snake_case`, без пробелов и точек.
- Значения — обычные строки; `{0}`, `{1}` — подстановки `string.Format`.
- Служебные поля начинаются с `_`:
  - `_languageName` — название в списке языков (на родном языке);
  - `_culture` — культура для чисел/дат (`ru-RU`, `en-US`, `de-DE`);
  - `_dateFormat`, `_dateFormatShort` — форматы дат.
- Ключи можно добавлять в любой файл. Недостающие ключи берутся из `en.json`,
  затем из `ru.json`, затем показывается сам ключ.

## Добавить новый язык

1. Откройте папку `lang` рядом с exe (в приложении: **Настройки → Папка
   языков**). В ней лежит краткая инструкция `README.md`.
2. Скопируйте `en.json` в `xx.json` (например, `de.json`).
3. Поменяйте `_languageName` на `Deutsch`, `_culture` на `de-DE`, переведите
   значения. Непереведённые ключи останутся английскими.
4. Нажмите кнопку перечитать рядом с выбором языка или перезапустите
   приложение. Новый язык появится в списке.
5. Для публикации языка в репозитории положите файл в
   `src/AefAccount/Localization/Lang/` и добавьте его в `AefAccount.csproj`
   (секция `Content` + `EmbeddedResource`).

## Тестирование

```powershell
AkEfLedger.exe --lang=en --page=settings
AkEfLedger.exe --lang=ru --page=overview
```

`--lang=xx` — разовый override для скриншотов и проверки; в настройки он не
записывается. Без аргумента работает обычное автоопределение.

## Что не переводится

- Имена операторов, оружия, достижений, доменов и коллекций приходят из API и
  SQLite как данные. Для операторов есть RU/EN-словарь в
  `Services/OperatorArt.cs`; остальное показывается как в источнике.
- Категории достижений и названия событий — данные API.
- Технические подписи `SKPORT API · SQLITE`, `PATCH`, `WORLD LEVEL` остаются
  частью визуального языка.

## Правила для разработчика

- Новая строка в XAML: `Text="{loc:Loc some_key}"`.
- Новая строка в коде: `L.T("some_key")` или `L.T("some_key", arg)`.
- Форматирование значения: `ConverterParameter=some_key` с
  `LocFormatConverter`.
- Не собирайте предложения конкатенацией: используйте один ключ с `{0}` —
  порядок слов в разных языках разный.
- После добавления ключей проверьте, что они есть в `ru.json` и `en.json`.
- Для вычисляемых строк моделей помните: страница пересоздаётся при смене
  языка, поэтому геттеры должны читать `L.T`/`AppCulture.Current` в момент
  вызова, а не кэшировать строку в конструкторе.
