# AK:EF Ledger v0.2.0 — private preview

## English

First prepared release of **AK:EF Ledger**, a local Windows dashboard for
Arknights: Endfield account data.

### Highlights

- Seven screens: Overview, Roster, Dynamics, Progress, Achievements, Snapshots,
  Settings.
- Snapshot archive with chart, timeline and A/B diff.
- Local operator art support with letter fallback.
- Settings with RU/EN placeholder, test operators and an in-memory DEV profile.
- Test character **Vesper** with AI-generated transparent assets.
- No telemetry, no server, no background network calls.

### Release asset

`AK-EF-Ledger-v0.2.0-win-x64.zip` contains the framework-dependent single-file
app, schema/seed, snapshot scripts and launch/update helpers.

### Notes

- Requires .NET 8 Desktop Runtime and Python 3.10+ for snapshots.
- Real operator artwork is not included; supply your own local files.
- This is an unofficial fan project, not affiliated with HYPERGRYPH/GRYPHLINE.
- The repository remains private while the public release is prepared.

## Русский

Первый подготовленный релиз **AK:EF Ledger** — локального дашборда для данных
аккаунта Arknights: Endfield.

### Главное

- Семь экранов: Обзор, Ростер, Динамика, Прогресс, Достижения, Снимки,
  Настройки.
- Архив снимков с графиком, таймлайном и A/B diff.
- Локальные арты операторов с буквой-заглушкой.
- Настройки: RU/EN-заглушка, тестовые операторы, DEV-профиль в памяти.
- Тестовая **Веспер** с прозрачными AI-ассетами.
- Без телеметрии, сервера и фоновых сетевых запросов.

### Файл релиза

`AK-EF-Ledger-v0.2.0-win-x64.zip` — framework-dependent single-file приложение,
schema/seed, скрипты снимков и launch/update-хелперы.

### Примечания

- Нужны .NET 8 Desktop Runtime и Python 3.10+ для снимков.
- Реальные арты операторов не входят; подключите свои локальные файлы.
- Неофициальный фанатский проект, не связан с HYPERGRYPH/GRYPHLINE.
- Репозиторий остаётся приватным, пока готовится публичный релиз.
